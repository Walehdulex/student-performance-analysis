# Student Performance Analysis

## Overview
This project explores a student performance dataset using Python and Pandas. The goal is to identify factors that influence academic outcomes.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning
- Exploratory data analysis
- Statistical summaries
- Data visualization

## Key Questions

**Does attendance impact exam scores?**
Yes, the analysis shows that students with higher attendance percentages generally achieved better exam scores, suggesting that consistent attendance may contribute to improved academic performance.

**Is study time correlated with performance?**
Yes, students who spent more hours studying generally achieved higher final exam scores, indicating that study habits have an important relationship with academic outcomes.

**Which factors contribute most to student success?**
Study time, attendance, previous grades, and other student-related factors such as sleep hours and extracurricular activities may contribute to academic success. Further analysis can help identify which factors have the strongest influence.

## Results and Key Findings

The analysis identified relationships between student behaviours and academic performance. Students with higher study hours generally achieved higher exam scores, and attendance showed a positive relationship with final exam performance. The dataset contained no missing values or duplicate records, making it suitable for analysis. Overall, study habits and attendance appear to be important factors influencing student outcomes.
